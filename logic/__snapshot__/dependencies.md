# What each theorem depends on

To trust a theorem, a reviewer reads its statement and the definitions it depends on: those defining the constants of its statement, and those defining the constants of theirs, through package logic and into package wasm, until only hol_light's constants are left. The proofs need no reading: the kernel checks them, and neither package adds an axiom. Generated by `logic/logic_test.mbt`; run `moon test --update` to refresh it.
